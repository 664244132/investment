## 1. กฎระเบียบในการทำงานและการใช้ Git (Git & Execution Rules)
- **ห้าม push หรือ commit ขึ้น GitHub (STRICT RULE 11):** 
  - ให้ผู้ใช้เป็นคนดำเนินการ push และ commit ขึ้น GitHub ด้วยตนเองเท่านั้น
- **Step-by-Step Development:**
  - ทำงานทีละขั้นตอน (Step-by-step) สรุปสิ่งที่แก้ไข แจ้งไฟล์ที่จะสร้าง/แก้ไขล่วงหน้า และรอการพิจารณาก่อนดำเนินการต่อ
- **Beginner-Friendly Code:**
  - เขียนโค้ดให้อ่านง่าย มีคอมเมนต์ภาษาไทยอธิบายจุดสำคัญ เพื่อให้ผู้เริ่มต้นเข้าใจได้ง่าย
